## 技能列表

| 技能 | 说明 |
|------|------|
| [cc-switch-skills-manager](./cc-switch-skills-manager-1.0.0/) | 跨 cc-switch、Claude、Codex 统一管理技能的迁移、链接同步和扫描 |
| [archive-manager](./archive-manager-1.0.0/) | 查看、管理并删除归档的 Claude Code 会话，支持活跃会话保护 |
| [claude-session-cleaner](./claude-session-cleaner-1.0.0/) | 清理 Claude Code 会话数据 |
